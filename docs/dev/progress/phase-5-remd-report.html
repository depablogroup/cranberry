CRANBERRY Phase 5 REMD Status Report

Developer status note for the REMD and MD-output contract update. REMD now has provenance metadata, interval controls, extra initial structures, and temperature-indexed DCD extraction. The MD CLI default-path regression is fixed through the new minimal smoke test.

Implemented

MD Defaults And Logs

  • cranberry md <pdb> --steps N is now covered by a minimal CLI smoke test and passes without --report-interval.
  • User-facing MD output density moved to --n-record; report_interval remains derived metadata/API compatibility.
  • The state log restores legacy fields: kinetic energy, total energy, elapsed time, and remaining time.
  • --write-minimization-report writes pre/post minimization total and force-group energies; the default path prints a compact total-energy note.

REMD Contract

  • --steps is total MD integration steps; OpenMMTools iterations are derived from steps // swap_steps.
  • --n-record derives the NetCDF checkpoint interval; --n-analysis 0 disables online analysis.
  • --extra-start-pdb adds a second coordinate source for alternating initial replicas.
  • args.json records REMD provenance while output.nc remains the authoritative restart artifact.

Known Follow-Up

PBC/box force behavior still needs a dedicated audit phase. Current REMD can carry topology box vectors into sampler states, but nonbonded/bonded force-level periodic behavior and DCD box-dimension handling should be reviewed before claiming full PBC support.
