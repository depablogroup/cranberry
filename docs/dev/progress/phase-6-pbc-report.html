CRANBERRY Phase 6 PBC Initial Slice Report

This report covers the first Phase 6 implementation slice: explicit opt-in periodic boundary conditions for MD and REMD, plus legacy-compatible force periodicity. This does not close all melting workflow work; it establishes the force and box semantics needed for subsequent double-stranded tests.

Latest committed implementation: 9d6ce04 Improve REMD platform provenance and PBC validation.

Legacy Audit Result

The legacy OpenMM-CGRNA/core/openRNA.py implementation toggles periodic methods for WCA, spline, Debye-Huckel, stacking, pairing, and RACER Buckingham nonbonded terms. It also calls setUsesPeriodicBoundaryConditions(self.pbc) for sugar-pucker custom compound/CV forces due to an OpenMMTools replica-exchange translation issue. Ordinary bond, angle, and dihedral terms do not opt into periodic distances.

Implemented

  • Added explicit periodic API arguments to CranberryForceField.createSystem, create_simulation, run_md, and RemdRunConfig.
  • Added cranberry md --periodic --box-padding and cranberry remd --periodic --box-padding.
  • Generated cubic boxes are explicit and centered from coordinates via prepare_periodic_positions.
  • REMD sampler states only receive box vectors when periodic=True; PDB CRYST1 is no longer enough to infer PBC.
  • MD/REMD provenance now records requested platform, actual_platform, periodic, and box_padding_nanometer; MD also records enforce_periodic_output. The default box padding is 2.0 nm.
  • MD DCD wrapping is separate from force PBC: --enforce-periodic-output defaults off.
  • MD and REMD write args.json after actual platform selection and before minimization/sampling; REMD --platform now configures the OpenMMTools context cache.
  • Periodic systems now validate force cutoffs against half the smallest box length before OpenMMTools context creation, so tiny boxes fail with an actionable --box-padding error.
  • CUDA REMD warns when online PyMBAR/JAX analysis is enabled because JAX may allocate GPU memory independently of OpenMM; --n-analysis 0 avoids that analysis path, and JAX_PLATFORM_NAME=cpu keeps online analysis off the GPU.

Behavior Contract

Force periodicity and MD trajectory wrapping are separate. periodic=True controls box/force physics; enforce_periodic_output=True controls MD DCD wrapping.

Known Follow-Up

This is not the full melting workflow closeout. Remaining Phase 6 work should add double-stranded melting fixtures, force-by-force minimum-image energy invariance tests, restart/NetCDF PBC compatibility checks, and clearer trajectory wrapping policy for production DCD/PDB outputs.
