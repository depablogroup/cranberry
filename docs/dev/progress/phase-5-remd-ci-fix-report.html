Phase 5 REMD CI Fix Report

Most recent commit e635763 added REMD tests while the base CI job installed only .[dev]. Because openmmtools is intentionally isolated behind the optional remd extra, GitHub CI needs to install the REMD extra when it is expected to exercise the REMD branch.

Fix

  • Changed the GitHub Actions install step to use python -m pip install -e ".[dev,remd]", so CI installs openmmtools and runs the REMD integration tests.
  • Removed the local pytest auto-skip hook from the prior attempted fix; REMD-marked tests should execute in GitHub CI rather than being skipped there.
  • Kept the REMD marker on CLI extraction tests because they create real REMD NetCDF files via run_remd.

Risk

Moderate. CI now depends on optional REMD dependencies resolving successfully, but this matches the desired branch validation behavior.

Validation

  • python -m pytest tests/test_cli.py::test_cli_help tests/test_cli.py::test_cli_remd_help -q
  • python -m pytest -q is expected to fail locally without openmmtools; GitHub CI should install it through .[dev,remd].
