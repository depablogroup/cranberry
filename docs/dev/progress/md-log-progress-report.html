MD Log Progress Option Review

Developer review note for adding an opt-in OpenMM progress column to Cranberry MD logs.

Code changes

  • Added run_md(..., log_progress=False) and forwarded it to OpenMM StateDataReporter(progress=...).
  • Recorded log_progress in args.json provenance.
  • Included log_progress in restart compatibility checks because appending to a log with a different column layout would corrupt the CSV-like output contract.
  • Added CLI flag cranberry md --log-progress.
  • Updated public output/tutorial docs to describe the optional Progress (%) log column.

Validation

  • python -m pytest -q tests/test_md.py::test_run_md_can_include_log_progress tests/test_cli.py::test_cli_md_help tests/test_cli.py::test_cli_md_log_progress_option passed: 3 tests in 13.27 s.
  • python -m pytest -q tests/test_md.py tests/test_cli.py was attempted. MD and CLI-focused tests ran, but REMD tests failed in this environment because openmmtools is not installed. The command also surfaced and the patch fixed the argparse percent escaping and missing test import issues.

Risks

  • The new option changes the standard log column set only when explicitly requested, preserving default output compatibility.
  • Restart compatibility now rejects mismatched log_progress settings to avoid appending rows with incompatible headers.
