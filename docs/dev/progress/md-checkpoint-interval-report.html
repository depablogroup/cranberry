MD Checkpoint Interval Report

This report covers the MD checkpoint cadence update: checkpoint writes are now decoupled from trajectory/log reporting.

Change

  • Added checkpoint_interval to run_md() and MDRunResult.
  • Added cranberry md --checkpoint-interval.
  • The default checkpoint interval is 10 * report_interval, so checkpoints are refreshed 10 times less often than DCD/log/detailed-log records by default.
  • args.json records checkpoint_interval for provenance.
  • The final explicit saveCheckpoint() remains, so completed runs still leave a latest checkpoint.

Validation

  • Focused MD/CLI tests cover default and explicit checkpoint intervals.
