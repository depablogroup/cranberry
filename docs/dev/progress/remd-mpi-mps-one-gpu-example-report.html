Important code paths

The batch allocation requests one GPU, eight tasks, four CPUs per task, 16 GB memory, and two hours. It enables OpenMMTools MPI, creates job-specific MPS pipe and log directories, starts MPS if available, and installs an exit trap that stops only a daemon this script successfully started. Missing MPS tooling produces a warning and allows the launcher to continue.

mps_started=0
stop_mps() {
    if [ "$mps_started" -eq 1 ]; then
        echo quit | nvidia-cuda-mps-control >/dev/null 2>&1 || true
    fi
}
trap stop_mps EXIT

srun -n "$N_REPLICAS" "$CRANBERRY_BIN" remd "$PDB_PATH" \
    --extra-start-pdb "$EXTRA_START_PDB" \
    --periodic --steps "$STEPS" --n-replicas "$N_REPLICAS" \
    --platform CUDA --output-dir "$OUTPUT_DIR"

Defaults use the bundled folded and extended ggcGCAAgcc structures, 100000 steps, and eight replicas (or Slurm's task count). Environment overrides remain those provided by PR #19.
