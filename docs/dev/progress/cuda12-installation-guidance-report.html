CUDA 12 Installation Guidance Report

Branch: codex/issue-6-cuda12-docs

Scope: public installation documentation only.

Why this changed

Issue #6 reproduced an OpenMM CUDA failure in a fresh CUDA 13 conda environment. OpenMM's self-test completed, but minimal real CUDA context creation failed with CUDA_ERROR_UNSUPPORTED_PTX_VERSION. The same style of environment using the CUDA 12 OpenMM target passed the CUDA context checks. This points to an OpenMM CUDA runtime, driver, and PTX compatibility issue in the target environment rather than a Cranberry input or force-field inconsistency.

Documentation changes

  • README.md: the recommended GPU install now pins cuda-version=12 when creating the conda environment.
  • README.md: added a short explanation that Cranberry's recommendation is based on local CUDA smoke testing, and that CUDA 13 failed during real OpenMM CUDA context creation in this environment.
  • docs/installation.md: mirrored the CUDA 12 conda pin for editable GPU development installs and for recreating an environment when the CUDA platform is missing.
  • docs/installation.md: added the rationale for documenting CUDA 12 even though OpenMM's general installation guide supports broader CUDA-version selection.

Important wording

conda create -n cranberry -c conda-forge python=3.11 openmm cuda-version=12
conda create -n cranberry-dev -c conda-forge python=3.11 openmm cuda-version=12

The docs also say to prefer a CUDA 12.9-compatible solve within the CUDA 12 line where one is available on the target cluster. This avoids claiming that CUDA 13 is universally broken while still documenting the Cranberry-tested environment that passed.

Validation

Risks and follow-up

  • The conda pin uses cuda-version=12 rather than an exact 12.9 pin so the solver can choose a compatible CUDA 12.x package set on clusters where exact minor availability differs.
  • A separate runtime diagnostic change can still improve the Cranberry API by translating OpenMM's unsupported PTX exception into a more actionable user-facing message.
