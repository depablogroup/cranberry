CRANBERRY Phase 4 Coarse-Graining Review

This slice adds the upstream coarse-graining entry point for atomistic RNA inputs while preserving the existing prepare/no-op/terminal-phosphate workflow for already coarse-grained inputs.

Review Finding

No blocking issues found

The new cg path is intentionally narrow: it converts a canonical atomistic RNA fragment into CRANBERRY CG beads, adds BC/BN virtual sites, writes CONECT records, and validates the output as a canonical input. The remaining risk is scope, not immediate correctness.

Core Behavior

Coarse-Graining Workflow

coarse_grain_structure() reads an atomistic PDB through OpenMM, maps each canonical RNA residue to the CRANBERRY bead set, adds BC/BN virtual-site atoms, and writes canonical CONECT records through the shared PDB writer.

result = coarse_grain_structure(
    "atomistic_input.pdb",
    output_path="atomistic_input_cg_vs_conect.pdb",
)
print(result.output_path)

Residue Mapping

The converter keeps the CRANBERRY output names used by the force field:

  • A: P, S3, S2, R1, A1, A2, BC, BN
  • U: P, S3, S2, Y1, U1, Y2, BC, BN
  • G: P, S3, S2, R1, G1, G2, BC, BN
  • C: P, S3, S2, Y1, C1, Y2, BC, BN

The backbone and base beads are copied directly from the atomistic coordinates. BC is the average of the three base beads, and BN is an out-of-plane site built from the base-bead triangle with the same heuristic scale used in the legacy utilities.

CLI Split

cranberry cg atomistic_input.pdb --output atomistic_input_cg_vs_conect.pdb
cranberry prepare input_cg_vs_conect.pdb --add-terminal-phosphate

cg coarse-grains atomistic input, then can optionally run the terminal-phosphate repair on the produced CG file. prepare stays a validation-first normalization step for already prepared CG input.

Residual Risk

  • Scope: this is a canonical atomistic-to-CG converter, not a general-purpose RNA cleaning pipeline.
  • Heuristic geometry: BC/BN placement remains a legacy-style heuristic, not a fitted physical model.
  • Documentation: any downstream docs that still describe cg as an alias must be updated before release.
