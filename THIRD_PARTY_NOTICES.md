# Third-Party Data and Services

The CRANBERRY source code, model parameter files, topology definitions, and project-authored generated fixtures are licensed under MIT. The following external data and services contributed source coordinates or idealized starting geometries.

## Protein Data Bank

Data files in the worldwide Protein Data Bank archive are available under the Creative Commons CC0 1.0 Universal dedication. CRANBERRY redistributes derived coarse-grained coordinates and one atomistic regression input from these entries:

| PDB ID | Structure DOI | Packaged derivative |
| --- | --- | --- |
| 157D | https://doi.org/10.2210/pdb157d/pdb | `157d_cg_vs_conect.pdb`, source of `2ntCG_cg_vs_conect.pdb` |
| 1L2X | https://doi.org/10.2210/pdb1l2x/pdb | `1l2x_cg_vs_conect.pdb` |
| 1ZIH | https://doi.org/10.2210/pdb1zih/pdb | Atomistic regression input, `1zih_cg_vs_conect.pdb`, and terminal-trimmed `ggcGCAAgcc_cg_vs_conect.pdb` |
| 2MI0 | https://doi.org/10.2210/pdb2mi0/pdb | `2MI0_cg_vs_conect.pdb` |
| 5ML7 | https://doi.org/10.2210/pdb5ml7/pdb | `5ml7_cg_vs_conect.pdb` |

The PDB archive encourages attribution to the original structure authors and associated publications. See https://www.rcsb.org/pages/policies.

## Web 3DNA

The initial atomistic geometries for `ggcGCAAgcc_extended_cg_vs_conect.pdb` and `rU40_cg_vs_conect.pdb` were generated by Yiheng Wu with the Web 3DNA fiber builder in single-stranded RNA mode. The resulting coordinates were subsequently coarse-grained with the CRANBERRY workflow.

Please cite:

- S. Li, W. K. Olson, and X.-J. Lu, "Web 3DNA 2.0 for the analysis, visualization, and modeling of 3D nucleic acid structures," *Nucleic Acids Research* 47, W26-W34 (2019), https://doi.org/10.1093/nar/gkz394.
- X.-J. Lu and W. K. Olson, "3DNA: a software package for the analysis, rebuilding and visualization of three-dimensional nucleic acid structures," *Nucleic Acids Research* 31, 5108-5121 (2003), https://doi.org/10.1093/nar/gkg680.

The current fiber interface and model documentation are available at:

- https://x3dna.org/articles/3dna-fiber-models
- https://x3dna.org/highlights/web-api-to-3dna
